# LearningVietnamese

Offline Vietnamese learning app for native-speaking primary-school pupils. Initial focus: Grades 1-2 reading and spelling; long-term vision: Grades 1-5.

Unity 6.6 is selected. Windows first, with possible Android/iOS expansion. Core learning targets ordinary laptops without a dedicated GPU. App implementation has not started.

Current work is product discovery and validation of attractive, responsive Unity UI that AI/code can author and edit effectively. App infrastructure, reusable exercises, and reviewed offline content come before gameplay.
